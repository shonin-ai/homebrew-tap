# Homebrew tap of Shonin

`shonin` sets up the AWS CLI and SDKs with the permission sets assigned to you in [Shonin](https://shonin.ai).

```sh
brew install --cask shonin-ai/tap/shonin
```

Update it with `brew upgrade --cask shonin`. The builds for macOS are signed and notarized by Apple.

How to sign in and use the profiles: https://docs.shonin.ai/command-line

The cask is updated by every release of `shonin`: changes made here by hand are overwritten.
